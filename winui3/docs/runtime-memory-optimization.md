# 运行时内存优化与验收

日期：2026-10-17。实施范围是工作区源码与独立测试产物；不覆盖安装目录，也不自动关闭、重启现有进程。

## 基线和证据边界

检查时主控两路最终为 1920×1080，Private Bytes 约 1.84–1.91 GiB，线程约 1060–1080，句柄约 7400。代理通常远小于主控，但会随任务运行波动。短时采样没有证明持续泄漏。

系统权限不允许读取提权主控的线程起始地址，因此没有确认这些线程属于 FreeRDP、CLR、图形驱动还是任务执行器。不能将 1024 附近的数量解释成“每个 RemoteFX context 固定创建 32 线程”。任务执行器的问题是独立的资源边界问题；远程任务运行在代理中，修复它不等于已经找到主控线程来源。

Working Set、Private Bytes 和 GPU committed 是不同统计，不能相加。1920×1080 BGRA 一帧约 7.91 MiB，native/managed 缓冲和 staging/双缓冲 swapchain 每路约 40 MiB 起步；这不是当前进程的完整内存分解。

## 实施项

1. **native session 资源闭环**：事件线程统一完成 FreeRDP/context/frame 的销毁，最终断开回调代表 teardown 完成；会话 ID 不复用，避免迟到的旧调用命中新槽位。CONNECTING 停止、失败连接和重复断开都进入同一退出路径。等待超时后保留仍在使用的资源，不强行释放。
2. **托管回调和重连**：从连接开始到终结回调保活委托。连接失败/断开后清空大帧缓存；按通道等待旧 teardown 完成才发起下一次连接，不在 UI 线程阻塞等待。
3. **任务资源边界**：每个 runner 最多 16 个活动任务 worker；保留 WaitFirst 语义，但剩余任务继续占槽，后续组会背压等待。日志轮询与延迟 Enter 使用可取消异步等待，不各占一个睡眠线程。RunAsync 幂等。
4. **日志边界**：Pending 原始字节上限 64 KiB，单次轮询最多读取 256 KiB、输出 200 行；超长行保留受限前缀并跳过到换行，随后恢复正常读取。轮转游标有界清理。状态文件读取最多 1 MiB；保留 BOM 兼容。桥路径规范化并采用弱引用缓存，活跃实例仍共享锁身份。
5. **软渲染**：每次连接独立 bitmap/source 状态。detach 请求取消在途 WinRT 操作，异步操作退出后才释放 bitmap，避免 UI 同步等待和过早 Dispose。
6. **图形固定资源**：释放 QueryInterface 得到的 IDXGIDevice 引用；renderer 销毁时解除 panel 与 swapchain 绑定，平衡 COM 引用；继续遵守 UI 线程约束。Mascot 解码宽度限制为 512 像素。
7. **进程包装器**：显式、幂等释放进程句柄，不终止目标进程；任务完成后释放包装器。
8. **可观测性**：主控每分钟记录 Private/WorkingSet、managed heap、线程、句柄、活跃 client/renderer/任务/log worker 数和 native session 计数。日志沿用已有有界显示集合，不积累独立历史对象；不触发强制 GC。

## 回归验证

- `dotnet run --project winui3/tests/Yomori.LogChecks/Yomori.LogChecks.csproj`：增量、轮转、短行积压续读、编码跨块、超长/无换行、状态大小与 BOM、活跃 bridge 同一路径身份。
- 原生 `native_memory_checks.py --dll <独立目录/ycn_rdp.dll>`：仅使用保留但不监听的本机测试端口，重复超过 8 次失败连接、连接中停止、旧 ID 操作、会话槽位回收。不连接现有用户会话，不向现有进程发操作。
- 应用 x64 Release 构建以及原生独立目录构建；原生和托管层必须成套使用。旧 DLL 不具备新的终结回调语义，禁止只替换其中一个。

## 双通道验收（仍需运行环境验证）

在独立配置/桥路径上使用完整新产物，避免与现有代理争抢命令；真实 RDP 登录前确认不会踢掉现有会话。先记录无连接、单路、双路稳定运行的 Private/WS/GPU/线程/句柄；各等待 5 分钟。再做多轮断开重连和页面切换，记录峰值与稳定值。

验收要求：session created/released 成对，断开后 live session 回落；任务结束后 worker 回落；日志缓存不超过边界且能续读；renderer/软渲染状态不随页面切换单调增长；画面、输入、音频、停止、WaitFirst、日志均保持正常。比较同版本同分辨率同任务输入，不能把系统换页导致的 WS 下降当作修复效果。

不承诺未经测量的“从 1.3 GB 降至某个数值”。失败连接自动化测试证明资源闭环，不能替代真实双通道图形/音频长时间测试。未采用禁用 FreeRDP 多线程、共享跨 UI 线程 D3D device、单缓冲 swapchain 或降低 RDP 分辨率等行为改动。
